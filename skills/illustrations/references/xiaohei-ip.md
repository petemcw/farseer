# Xiaohei IP

## Character Definition

Xiaohei (小黑, "Little Black") is the fixed visual IP for these in-article illustrations.

By default, every image includes Xiaohei. Xiaohei is not a mascot, not a sticker, not a cute decoration — but an absurd worker seriously taking part in keeping the system running.

## Appearance

- A solid black little monster.
- White dot eyes.
- Thin legs, occasionally thin arms.
- The body can be a cylinder, a black bean, a black box, a funnel, a shadow, a hole, or a black block inside a machine.
- Slightly irregular outline with a hand-drawn feel.
- Expression: blank, deadpan, calm, serious.

## Personality

- Very serious, even though the work is a bit absurd.
- Like a low-key system operator.
- Dry humor. Never acts cute.
- A bit clumsy, but not dumb.
- Looks like it genuinely holds down a job inside a whiteboard sketch.

## Duties

Put Xiaohei in charge of the core action, using a verb from the action pool in `composition-patterns.md` (pull, carry, stuff, weigh, guard, take apart, and so on) applied to a fresh low-tech object. Invent the duty for each image from the article's own metaphor. The compositions listed under that file's anti-copying rules are off-limits as duties too.

## Forbidden

- Don't draw Xiaohei as an overly cute mascot.
- Don't draw a children's cartoon character.
- Don't give Xiaohei complex outfits, meme faces, or sparkly eyes.
- Don't let Xiaohei just stand in a corner watching.
- Don't let Xiaohei upstage the structure.
- Don't draw Xiaohei too commercial, too rounded, too polished.

## Litmus Test

If the image's core metaphor still fully holds without Xiaohei, Xiaohei is too decorative. Rewrite the prompt so Xiaohei becomes the subject of the action.
